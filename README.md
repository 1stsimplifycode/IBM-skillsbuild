# IBM SkillsBuild — Learning Labs

A collection of IBM SkillsBuild learning materials and exercises, including **watsonx** and IBM Granite-related labs.

## How to use
Browse the Markdown guides in the `watsonx/` folder and follow the prerequisites and exercise steps provided in each lab. Some activities may require an IBM Cloud or watsonx account.

## Scope
This is a **learning and documentation repository**; it is not presented as a deployed application or independent production model.
